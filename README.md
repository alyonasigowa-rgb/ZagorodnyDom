# Свой дом — лендинг частного риэлтора по загородной недвижимости

Одностраничный сайт (лендинг) для частного риэлтора, который подбирает загородные дома и сопровождает сделку «под ключ»: от проверки документов до регистрации права собственности.

## Решаемая задача

Покупка загородного дома — рискованная сделка для неподготовленного покупателя. Люди сталкиваются со скрытыми дефектами (септик, фундамент, проводка), проблемами с границами участка и юридической чистотой документов, а также выгорают от бесконечных просмотров.

Лендинг решает три задачи бизнеса:

1. **Доносит ценность услуги** — объясняет, какие риски есть при самостоятельном поиске и как их убирает риэлтор (проверка инженерии, юридическая экспертиза, первичный отсев объектов).
2. **Снимает возражения** — прозрачные условия оплаты, отсутствие предоплаты за «процесс поиска», гарантия «не нашли — не платите».
3. **Собирает заявки** — форма заявки на бесплатный брифинг отправляет данные (имя и телефон) в Google Таблицы через Google Apps Script.

## Целевая аудитория

- Семьи, которые хотят переехать за город и ищут дом для постоянного проживания.
- Люди, уже нашедшие дом самостоятельно, но боящиеся скрытых проблем и нуждающиеся в технико-юридической экспертизе объекта.
- Покупатели с ограниченным бюджетом, которым важен торг и контроль каждого этапа сделки.

## Функциональность

- **Бесконтактная форма заявки** — отправка данных в Google Apps Script (без сервера).
- **Плавные анимации появления блоков** при прокрутке (IntersectionObserver).
- **Параллакс-эффекты** на изображениях.
- **Адаптивная вёрстка** — мобильное меню, перестроение сеток под все экраны.
- **Кастомный типографический стиль** — шрифты Fraunces и Inter.
- Поддержка `prefers-reduced-motion` для пользователей с отключённой анимацией.

## Технологии

- HTML5, CSS3, чистый JavaScript (без фреймворков и сборщиков)
- Google Apps Script (Web App) для приёма заявок
- Google Fonts (Fraunces, Inter)

## Как запустить локально

Лендинг статический — сервер не требуется. Достаточно открыть `index.html` в браузере или запустить любой локальный веб-сервер:

```
python -m http.server 8000
```

Затем открыть http://localhost:8000

## Отправка заявок

Форма отправляет `POST`-запрос в Google Apps Script (адрес задаётся константой `LEAD_FORM_ENDPOINT` в `script.js`). При необходимости подключите свой скрипт или замените endpoint на собственный бэкенд.
